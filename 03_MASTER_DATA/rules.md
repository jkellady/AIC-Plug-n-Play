# Attendance rules (v0.1, Phase 1 trial)

Status: CONFIRMED = given by Client. ASSUMED = used for now, waiting for Client to confirm.

| Rule | Value | Status |
|---|---|---|
| Morning opening | 10:00 | CONFIRMED (C6) |
| Clock-in 09:45 or 09:50 | Not "early". Recorded as 10:00 | CONFIRMED (C6) |
| Late-in grace | 15 minutes | CONFIRMED (C5) |
| Late-in cleared when | Explained and agreed by the office or a superior | CONFIRMED (C5). How the approval reaches the system is OPEN (Q8) |
| Late-in deduction | Actual minutes, or round up to :30 as HQ does today | OPEN (Q1). Report shows actual minutes and flags the rounding |
| Outlet transfers | Flag and highlight, not an error | CONFIRMED (C4) |
| Overtime | Agent checks clock times and sums. Final calculation is a later HR task | CONFIRMED (C7) |
| Time after scheduled end | Not counted | ASSUMED (Q2) |
| Early-out grace | 15 minutes | ASSUMED (Q5) |
| AM / PM / FULL | 10:00-18:00 / 14:00-22:00 / 10:00-22:00 | ASSUMED (matches HQ typed times) |
| Standard day | 8h30, as in the record tab formulas | ASSUMED |
| Staff and outlet IDs | Initials as provided in the files | CONFIRMED (C1, C2) |
| WhatsApp to staff | On hold. Later from GHL contact list | CONFIRMED (C8) |
| Writing into record tabs | None. Phase 1 is read-only | Write policy OPEN (Q4) |
